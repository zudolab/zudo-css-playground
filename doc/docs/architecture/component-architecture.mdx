# Component Architecture

All interactive components are React islands rendered within an Astro layout. The base layout composes them into a two-column sidebar + content structure.

## Base Layout

**File**: `src/layouts/base-layout.astro`

The base layout wraps every page and provides the shell structure.

```astro
---
import "../styles/tokens.css";
import SidebarNav from "../components/sidebar-nav.tsx";
import ColorTweakPanel from "../components/color-tweak-panel.tsx";
import AiChatModal from "../components/ai-chat-modal.tsx";

interface Props {
  title: string;
  activeCategory?: string;
}

const { title, activeCategory } = Astro.props;
---

<body class="min-h-screen">
  <div class="flex min-h-screen">
    <!-- Sidebar: 250px fixed width -->
    <aside class="w-[250px] shrink-0 bg-surface ...">
      <SidebarNav client:load activeCategory={activeCategory} />
      <button onclick="window.dispatchEvent(new Event('toggle-ai-chat'))">
        AI Chat
      </button>
    </aside>
    <!-- Main content: fluid -->
    <main class="flex-1 p-vsp-xl overflow-auto">
      <slot />
    </main>
  </div>
  <!-- Floating islands -->
  <ColorTweakPanel client:load />
  <AiChatModal client:load />
</body>
```

### Layout Details

- **Two-column layout**: Fixed 250px sidebar + fluid main content area
- **No TOC**: The main area is a simple content slot with no table of contents
- **Token import**: `tokens.css` is imported here, making all design tokens available globally
- **AI Chat toggle**: Uses `window.dispatchEvent(new Event('toggle-ai-chat'))` — the AiChatModal listens for this event

## HtmlPreview

**File**: `src/components/html-preview.tsx`

Iframe-based live CSS demo renderer. Each pattern is displayed inside an isolated iframe with its own CSS.

### Props

```typescript
interface Props {
  html: string; // HTML content to render
  css: string; // CSS styles injected into iframe
  title?: string; // Panel title/label
  height?: number; // Fixed height in px; auto-measured if omitted
  defaultOpen?: boolean; // Code section initially expanded (default: false)
}
```

### Features

- **Viewport switching**: Three buttons — Mobile (320px), Tablet (768px), Full (100%)
- **Code toggle**: Show/Hide button reveals the HTML and CSS source in a collapsible section
- **Auto-height measurement**: When no `height` prop is given, measures `body.scrollHeight` after iframe load and adds 16px padding
- **Sandbox security**: Uses `sandbox="allow-same-origin"` to prevent script execution while allowing CSS to work
- **Hydration**: Uses `client:visible` to defer hydration until scrolled into view

### BASE_TOKENS Injection

Every iframe receives a shared set of simplified design tokens via the `BASE_TOKENS` constant:

```css
:root {
  --space-xs: 8px;
  --space-sm: 12px;
  --space-md: 20px;
  --space-lg: 32px;
  --radius: 8px;
  --accent: hsl(220 70% 50%);
  --accent-hover: hsl(220 70% 42%);
  --fg: hsl(220 25% 15%);
  --fg-muted: hsl(220 10% 40%);
  --bg: hsl(0 0% 100%);
  --bg-subtle: hsl(220 15% 96%);
  --border: hsl(220 15% 85%);
  --success: hsl(142 71% 45%);
  --danger: hsl(0 84% 60%);
  --warning: hsl(45 93% 47%);
  --info: hsl(220 70% 50%);
  --font-sm: 0.85rem;
  --font-md: 1rem;
  --font-lg: 1.1rem;
  --shadow: 0 1px 3px hsl(220 25% 15% / 0.1);
  --shadow-strong: 0 4px 12px hsl(220 25% 15% / 0.15);
  --focus-ring: 0 0 0 2px hsl(220 70% 50% / 0.25);
}
```

These are simplified aliases (e.g., `--space-xs` instead of `--spacing-hsp-xs`) designed for use inside pattern demos. The iframe also includes a global CSS reset and `:focus-visible` outline.

## SidebarNav

**File**: `src/components/sidebar-nav.tsx`

Category navigation rendered in the sidebar.

### Props

```typescript
interface Props {
  activeCategory?: string; // Current page slug for highlighting
}
```

### Categories

The category list is a hardcoded array at the top of the file:

```typescript
const categories = [
  { slug: "headers", label: "Headers", count: 8 },
  { slug: "cards", label: "Cards", count: 8 },
  { slug: "forms", label: "Forms", count: 6 },
  { slug: "tabs", label: "Tabs", count: 6 },
  { slug: "toasts", label: "Toasts", count: 4 },
  { slug: "footers", label: "Footers", count: 4 },
];
```

Each category links to `/{slug}` and shows the pattern count in muted text.

### Styling States

| State   | Classes                                            |
| ------- | -------------------------------------------------- |
| Default | `text-fg hover:bg-surface hover:text-accent-hover` |
| Active  | `bg-accent/15 text-accent font-medium`             |

The AI chat API can update this file programmatically when new categories are created (see [AI API](/specs/ai-api)).

## ColorTweakPanel

**File**: `src/components/color-tweak-panel.tsx`

Floating, draggable color palette editor.

### Toggle Button

A fixed circular button (36×36px) in the top-right corner with a gradient background (`#89b4fa → #f5c2e7 → #a6e3a1`). Click to open/close the panel.

### Panel Layout

- **Position**: Fixed, defaults to top-right (window width − 300, 16)
- **Size**: 280px wide, max-height `calc(100vh - 32px)` with vertical scroll
- **Drag**: Title bar is draggable, constrained to viewport bounds

### Editing Modes

The panel has two sections:

**Palette (p0–p15)**: 16 color input pickers arranged in a 4×4 grid. Each maps to `--cssp-0` through `--cssp-15`.

**Semantic**: 10 color input pickers in a 2-column grid:

| Field     | CSS Variable          |
| --------- | --------------------- |
| BG        | `--cssp-bg`           |
| FG        | `--cssp-fg`           |
| Surface   | `--cssp-surface`      |
| Muted     | `--cssp-muted`        |
| Accent    | `--cssp-accent`       |
| Acc Hover | `--cssp-accent-hover` |
| Success   | `--cssp-success`      |
| Danger    | `--cssp-danger`       |
| Warning   | `--cssp-warning`      |
| Info      | `--cssp-info`         |

### Presets

Three built-in presets (see [Color Architecture](/specs/color-architecture) for full hex values):

- Catppuccin Mocha (default)
- Dracula
- Nord

Select a preset from the dropdown or click **Reset** to restore the current preset's defaults.

### Persistence

Three localStorage keys:

| Key                   | Purpose                               |
| --------------------- | ------------------------------------- |
| `cssp-tweak-state`    | Full color state (palette + semantic) |
| `cssp-tweak-position` | Panel x,y coordinates                 |
| `cssp-tweak-preset`   | Active preset name                    |

### Live DOM Updates

The `applyToDocument()` function sets CSS custom properties directly on `document.documentElement.style`. Since all page styles reference `--cssp-*` variables, changes propagate instantly.

## DemoTweakPanel

**File**: `src/components/demo-tweak-panel.tsx`

Floating, draggable panel for live-editing demo tokens inside HtmlPreview iframes.

### Toggle Button

A fixed circular button (36x36px) at `top: 12px, right: 56px` (offset from the ColorTweakPanel button). Gradient background (`#f9e2af -> #94e2d5 -> #89b4fa`) with a ruler/grid SVG icon.

### Panel Layout

- **Position**: Fixed, centered on viewport when opened
- **Size**: 280px wide, max-height `calc(100vh - 32px)` with vertical scroll
- **Drag**: Title bar is draggable, constrained to viewport bounds

### Tabbed UI

Three tabs control which token category is shown:

| Tab            | Controls                                               | Widgets                                                  |
| -------------- | ------------------------------------------------------ | -------------------------------------------------------- |
| **Color**      | `--accent`, `--fg`, `--bg`, `--border`, status colors  | Clickable color swatches that open an HSL picker popover |
| **Typography** | `--font-sm`, `--font-md`, `--font-lg`                  | Text input + range slider (0.5-3rem, step 0.05)          |
| **Spacing**    | `--space-xs`, `--space-sm`, `--space-md`, `--space-lg` | Text input + range slider (0-64px, step 1)               |

### Color Tab Sections

- **Palette Colors**: `--accent`, `--accent-hover`, `--fg`, `--fg-muted`, `--bg`, `--bg-subtle`, `--border`
- **Status Colors**: `--success`, `--danger`, `--warning`, `--info`

Clicking a swatch opens the `HslPicker` popover component for fine-grained HSL editing.

### Iframe Communication

Token changes are applied to all registered HtmlPreview iframes via the iframe registry (`src/lib/iframe-registry.ts`):

- `applyToAllIframes(variable, cssValue)` — updates a single token
- `setGlobalOverrides(overrides)` — applies all overrides (used on mount)
- `resetGlobalOverrides()` — removes all overrides (used by Reset button)

### Persistence

| Key                | Purpose                                                                    |
| ------------------ | -------------------------------------------------------------------------- |
| `demo-tweak-state` | Full state (colors as hex, typography as rem values, spacing as px values) |

The **Reset to Defaults** button clears localStorage and restores all tokens to their default values from `demoTokenConfig`.

## AiChatModal

**File**: `src/components/ai-chat-modal.tsx`

Modal dialog for AI-powered pattern generation.

### HTML Dialog

Uses the native `<dialog>` element with `showModal()`. Features:

- Backdrop click to close
- Keyboard `Escape` to close (built into `<dialog>`)
- AbortController cancellation for in-flight requests
- Message history cleared on close

### Message Structure

```typescript
interface ChatMessage {
  role: "user" | "assistant";
  content: string;
  needsReload?: boolean; // Show reload button
  filesWritten?: string[]; // List of created files
}
```

### Loading Phases

The modal shows staggered status messages during AI requests:

1. **Immediately**: "Understanding your request..."
2. **After 1500ms**: "Generating patterns with AI..."
3. **On success**: "Writing files and updating navigation..."

### Reload Flow

When the AI successfully creates pattern files, the assistant message includes:

- A list of written files (e.g., "Files: breadcrumbs.astro")
- A **Reload page to see results** button that calls `window.location.reload()`

### Event-Driven Toggle

The modal listens for a `toggle-ai-chat` window event dispatched by the sidebar button in the base layout:

```javascript
window.addEventListener("toggle-ai-chat", handler);
```
